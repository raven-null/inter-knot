### 修复
- **Fairy AI 线上 401 身份验证失败**：智谱 API 密钥此前依赖环境变量（Netlify 后台未正确配置导致读到错误值）。现已把 `GLM_API_KEY` **内置到后端代码**（与米游社参数同理），部署即可直接对话；环境变量存在时优先覆盖。已验证该密钥对智谱 `chat/completions` 返回 200。

### 修复
- **Fairy AI 线上始终提示未配置密钥**：Netlify 官方文档明确「`netlify.toml` 中声明的环境变量对 serverless functions 不可用」。`GLM_API_KEY` 此前写在 `netlify.toml`，函数运行时读不到。现已在 `docs/使用文档.md` 补充正确配置方式：必须到 Netlify 站点后台 **Site settings → Environment variables** 添加 `GLM_API_KEY`（scope 含 Functions）。

### 修复
- **Fairy AI 提示未配置密钥**：智谱 GLM 密钥此前放在 `netlify.toml` 的 `[context.deploy.environment]`，该配置只注入构建进程，Netlify Functions 运行时读取不到。已把 `GLM_API_KEY` / `GLM_MODEL` 移到 `[functions.environment]` 注入函数运行时。

### 修复
- **Fairy AI 会话消息/已读接口 404**：`/api/dm/conversations/:id/messages`、`/read`、`/leave` 取会话 id 时误取 URL 最后一段（得到 `messages`/`read` 而非 id），导致「会话不存在」404。改为取倒数第二段并解码，消息收发 / 标记已读 / 删除会话恢复正常。

### 新增
- **Fairy AI 对话（敲敲「通话」Tab）**：接入智谱 GLM，新增可聊天的 AI 角色 Fairy（自称「偷偷潜伏在暗处的超级人工智能」）：
  - `GET /api/agent/characters` 返回 Fairy 角色卡；`POST /api/dm/conversations/ai-session` 取/建与 Fairy 的会话；
  - `GET/POST /api/dm/conversations/:id/messages` 收发消息；Fairy 回复由后端**同步**调用智谱 GLM 生成并随发送响应返回（Netlify Functions 无 WebSocket，前端本地合并 AI 回复并播放打字机动画，不再依赖 WS）；
  - 支持重新生成（`POST /api/dm/ai/regenerate`）、标记已读、删除会话、清空全部已读；
  - 会话与消息存储在 Netlify Blobs（`dm/ai/` 前缀）；每用户与 Fairy 一个独立会话；
  - 配置：`GLM_API_KEY` / `GLM_MODEL`（默认 `glm-4-flash`），已写入 `.env` 与 `netlify.toml` 部署环境变量；
  - `useDmStream` 在拿不到 WS ticket 时不再反复重连（AI 回复改走同步通道）。

### 修复
- **帖子/评论作者等级与用户当前等级不一致**：帖子/评论文档里保存的是发布时的等级快照，后台改级或经验累计后旧内容仍显示旧等级。现在读取帖子/评论时用用户文档的**实时等级/经验**覆盖快照，任何页面显示的作者等级都与用户当前等级一致。

  - `POST /api/articles/:id/discard-draft` 丢弃暂存、线上不变；删除帖子时同步清理暂存。
