# 绳网论坛 功能文档

本文档罗列当前阶段论坛（绳网）的全部功能，分为**前台**与**后台**两大部分。技术栈：Nuxt 4（Vue 3）前端 + Netlify Functions 后端 + Netlify Blobs 存储。

---

## 一、账号与登录

### 登录方式
- **米游社扫码登录**：首次登录的唯一入口。扫码后自动创建绳网账号，并生成 16 位登录密钥（仅显示一次，需妥善保管）。
- **密钥登录**：输入米游社登录时生成的密钥直接登录，无需再次扫码。
- 密钥丢失可重新扫码登录获取新密钥。
- 令牌（JWT）存浏览器 localStorage，登录态持久保持，过期后自动续期。

### 账号中心（`/account`）
- **登录密钥**：账号部分展示当前密钥（默认掩码显示，点击可显示原文，带复制按钮）。
- **米哈游账号**：查看已绑定的绝区零角色信息（昵称 / UID / 服务器）；未绑定时可扫码绑定；支持解除绑定。
- **黑名单**：管理已屏蔽的用户，可解除拉黑。

## 二、首页与信息流（`/`）

### 信息流
- **推荐流**：默认展示全站最新已发布帖子。
- **关注流**：仅展示我关注的作者发布的帖子（需登录）。
- **收藏流**：仅展示我收藏的帖子（需登录）。
- 瀑布流虚拟列表：横向自适应列数，长列表流畅滚动。
- 卡片支持**多图轮播**：多图帖子在卡片上悬停可切换查看各张图片。

### 频道筛选
- 按版块（分类）筛选帖子，每个版块有独立的信息流。
- 版块「全部」下拉可查看更多分类；关注/收藏流不与分类叠加。

### 搜索
- 顶部搜索框支持按**标题/正文**搜索帖子。
- 输入时实时联想（suggest），历史搜索记录。
- 搜索仅对推荐流生效。

### 新帖提醒
- 后台轮询发现新发布的帖子时，顶部弹出「有 N 条新内容」胶囊按钮，点击即插入最新内容。
- 支持下拉刷新手动刷新信息流。

---

## 三、发帖（`/create`）

### 编辑器
- 标题 + 正文（Markdown 编辑，带工具栏：加粗 / 斜体 / 标题 / 引用 / 代码块 / 列表 / 链接 / 图片 / 提及 / 表情等）。
- 封面图片：支持**多图上传**（第一张为封面）；图片自动转 WebP（≤4MB 原图、最长边 2048px、质量 80、剥离 EXIF），超限大图上传前自动压缩。
- 外链视频：可嵌入 B 站视频（通过 BilibiliVideoDialog 粘贴链接自动解析）。
- 选择分类（版块）发布。

### 草稿箱
- 编辑过程**自动保存**为草稿，可随时恢复继续编辑。
- 草稿列表在编辑器侧栏展示，支持删除草稿。
- 已发布帖子的编辑走草稿暂存，点「更新帖子」后重新发布。

### 发布选项
- **匿名发布**：帖子不显示作者身份。
- 发布后立即进入信息流，可在首页与个人主页看到。

---

## 四、帖子详情（`/post/:id`）

### 正文
- Markdown 渲染（DOMPurify 过滤 XSS，代码高亮）。
- 图片灯箱浏览（useLightGallery）。
- 支持外链 B 站视频播放。

### 多图展示
- 帖子发布多张图片后，**首页卡片 / 帖子弹窗 / 详情页**均以轮播方式展示全部图片（Embla）。
- 轮播支持左右切换按钮、圆点指示器、`1 / N` 计数、左右滑动/水平滚轮切图。
- 点击任意一张可放大并在灯箱中浏览全部图片。

### 互动
- **点赞 / 取消点赞**。
- **一键三连**（长按点赞触发）：点赞 + 收藏 + 丁尼，带 B 站风格蓄力动画。
- **收藏 / 取消收藏**。
- **举报**：选择举报原因提交给后台。
- 浏览量统计（进入详情自动 +1，已读记录）。
- 帖子作者可**置顶 / 取消置顶**自己的精选帖子展示。

### 评论
- 楼中楼评论（可回复评论）。
- 评论支持图片上传、@提及（MentionPicker 实时搜索用户）、表情（EmotePicker）。
- 评论可点赞、删除（作者本人）。
- 评论楼主（作者）可置顶 / 取消置顶某条评论。
- 评论区 `@fairy` 可与 Fairy AI 对话（后端调用智谱 GLM 生成楼中楼回复）。

### 内容安全
- NSFW 图片遮罩：敏感图默认模糊，点击揭示。

## 五、个人主页（`/profile/:id`）

- **名片横幅**：背景图（名片）+ 头像 + 昵称 + 绳网等级（Lv + 称号）+ 绝区零角色徽章 + 简介签名。
- **统计**：帖子数 / 评论数 / 总浏览 / 获赞等。
- **帖子列表**：该作者发布的帖子（瀑布流展示）。
- **评论 / 收藏 / 浏览历史** Tab。
- 悬停其他用户头像/昵称可弹出**悬浮名片**（UserHoverCard：背景、头像、昵称、签名、等级、统计）。
- 支持**关注 / 取消关注**、**拉黑 / 解除拉黑**、私信入口。
- 本人可编辑：
  - **修改用户名**（消耗丁尼）
  - **修改签名（简介）**
  - **修改头像**：内置头像 + 自定义裁剪上传（WebP）
  - **修改名片**：内置名片背景 + 自定义背景上传 + 装备 / 卸下
  - **修改帖子展示**：从自己的已发布帖子中精选若干置顶展示
  - **社交设置**：隐藏个人资料（其他用户看不到签名 / 统计 / 名片 / 帖子 / 评论）
  - **账号中心** / **退出登录**

## 六、等级体系（`/level`）

- 绳网等级：用户通过**发帖、评论、获赞**累积经验升级。
- 经验规则：发布帖子 +4（每日首次）、发表评论 +3（每日首次）、每收到 1 个赞 +1。
- 等级环（SVG 进度）、当前等级称号、升级所需经验、全等级一览表（Lv.1–Lv.7 门槛与称号）。
- 全站等级开关可由后台控制（`showLevel`）。

---

## 七、敲敲（私信 / 群聊 / AI）

### 入口
- 顶部导航「敲敲」图标，弹窗式聊天界面（KnockKnockModal）。

### 通话 Tab（AI 对话，Fairy）
- 与 AI 角色 Fairy（自称「偷偷潜伏在暗处的超级人工智能」）对话，回复由智谱 GLM 生成。
- 打字机式逐字展示回复；支持停止生成、重新生成、清空会话上下文。
- 后台可开关「AI 对话」（`showAi`）。

### 私聊 Tab
- 向任意用户发起私聊（个人主页「私信」按钮）。
- 会话列表（含 AI 与群聊合并展示）。
- 消息支持编辑、撤回、复制、已读标记、置顶 / 静音会话、删除会话。
- 未读消息数红点提示。

### 群聊 Tab
- 创建群聊（群名 + 拉人），邀请成员，多人一起聊天。
- 成员管理：拉人、离开群聊。

### 消息富文本
- 消息支持 Markdown 渲染、@提及、表情、图片。
- 引用帖子卡片、代码块复制等。

## 八、后台管理（`/admin`）

> 仅管理员（role=admin）可访问。用管理员账号登录后，顶部导航「后台」进入。

### 数据概览（`/admin`）
- 顶部卡片：注册用户 / 帖子总数 / 评论总数 / 总浏览量 / 今日新帖 / 今日评论 / 待审核 / 版块数 / 在线人数。
- 近 30 天趋势图（新帖 / 新评论 / 新用户）。
- 最新注册用户、最新帖子列表。

### 用户管理（`/admin/users`）
- 按用户名 / 昵称 / UID 搜索。
- 调整角色：用户 / 版主 / 管理员。
- 调整等级（Lv.1–Lv.7）。
- 禁用 / 解禁账号（禁用后无法登录）。
- 彻底删除用户（连带其帖子、评论、绑定、上传）。

### 帖子管理（`/admin/posts`）
- 按标题 / 正文搜索，按状态筛选（已发布 / 待审核 / 草稿 / 已删除）。
- 操作：置顶 / 取消置顶、下架 / 恢复显示、发布、删除。

### 帖子审核（`/admin/review`）
- 待审核帖子队列：一键通过（发布）或驳回（退回作者草稿箱）。

### 评论管理（`/admin/comments`）
- 按内容搜索，删除违规评论。

### 举报管理（`/admin/reports`）
- 查看用户举报列表，处理（忽略 / 删除对应内容等）。

### 版块管理（`/admin/categories`）
- 新增 / 编辑 / 删除版块。
- 调整排序、隐藏 / 显示、标记管理员专属分区。

### 导航与功能开关（`/admin/forum`）
- **导航开关**：搜索框、在线人数、敲敲、发布导航、后台导航。
- **功能开关**：等级体系（`showLevel`）、AI 对话（`showAi`）。
- **公告**：编辑首页公告。
- **表情包管理**：新增 / 删除表情与分组（前台评论 / 发帖 / 私聊均可使用）。
- **版块管理入口**（标签管理）。

### 站点设置（`/admin/settings`）
- 站点名称、公告、是否开放注册、新帖是否需审核。

## 九、通用交互与体验

- **全局背景跑马灯**：绝区零风格滚动字幕（标题 / 公告），GPU 加速降载。
- **虚拟滚动**：信息流瀑布流、聊天消息列表，保证大列表流畅。
- **图片优化**：上传即转 WebP、剥 EXIF；列表用缩略图懒加载。
- **表情系统**：全局表情包（EmotePicker / MobileEmotePicker），支持自定义分组。
- **@提及**：评论区 / 私聊中 @ 实时搜索用户并高亮。
- **全文 XSS 防护**：所有富文本经 DOMPurify 过滤。
- **响应式**：桌面 / 移动端自适应布局，移动端底部导航栏。
- **悬停卡**：桌面端悬浮用户名片。
- **新帖 / 刷新提示**、下拉刷新、页面进度指示。

## 十、数据与存储（技术要点）

- 存储使用 **Netlify Blobs**：
  - `data` store：结构化 JSON（用户 / 帖子 / 评论 / 版块 / 设置 / 统计 / 索引）。
  - `uploads` store：图片字节（`<contentHash>.webp`，内容级去重）。
- 信息流索引：`_indexes/feed.json` 维护最新已发布帖子，供列表 / 搜索 / 分页。
- 作者信息实时水合：读取帖子 / 评论时用用户文档实时数据覆盖作者昵称 / 头像 / 等级，用户改名换头像后旧帖子即时同步。
- 无数据库依赖，数据随站点 Blobs 持久化，重新部署不清空。
