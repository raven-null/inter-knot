# 绳网论坛 项目信息

## 项目概述

绳网论坛（InterKnot Forum）是一个复刻《绝区零》游戏绳网风格的论坛系统，采用前后端分离架构，可部署到 Netlify 平台。

## 基本信息

| 项目 | 说明 |
|------|------|
| 项目名称 | 绳网论坛（InterKnot Forum） |
| 版本 | 0.2.0 |
| 仓库地址 | https://github.com/raven-null/inter-knot |
| 线上地址 | https://interknot.netlify.app |
| 技术栈 | Nuxt 4 + Vue 3 + Netlify Functions + Netlify Blobs |
| 开发语言 | TypeScript |
| 包管理器 | npm |

## 技术架构

### 前端架构

```
Nuxt 4 (Vue 3)
├── 状态管理：Pinia
├── 数据获取：TanStack Vue Query
├── UI 组件库：自研 zenless-ui
├── 图片灯箱：lightgallery
├── 轮播组件：embla-carousel-vue
├── Markdown：markdown-it + DOMPurify
├── 代码高亮：highlight.js
└── 图片裁剪：vue-advanced-cropper
```

### 后端架构

```
Netlify Functions v2
├── 单入口路由：api.ts
├── 存储层：Netlify Blobs
│   ├── data store：结构化 JSON
│   └── uploads store：图片字节
├── 认证：JWT (jose)
├── 图片处理：sharp
└── AI 对话：智谱 GLM
```

### 数据存储

| 存储类型 | 用途 | 位置 |
|----------|------|------|
| 用户数据 | 用户信息、设置 | `users/<id>.json` |
| 帖子数据 | 帖子内容、元数据 | `posts/<id>.json` |
| 评论数据 | 评论内容、层级关系 | `comments/<postId>/<id>.json` |
| 会话数据 | 私聊/群聊会话 | `dm/conv/<id>.json` |
| 通知数据 | 站内通知 | `notifications/<userId>/<id>.json` |
| 上传文件 | 图片字节 | `uploads/<hash>.webp` |
| 索引数据 | 信息流、草稿等 | `_indexes/*.json` |

## 核心模块

### 1. 认证系统

- **登录方式**：米游社扫码登录 + 密钥登录
- **令牌管理**：JWT，自动续期
- **权限控制**：管理员/普通用户角色

**相关文件**：
- 后端：`netlify/functions/_lib/auth.ts`
- 前端：`app/stores/auth.ts`
- 路由：`netlify/functions/_lib/routes/auth.ts`

### 2. 帖子系统

- **发帖**：Markdown 编辑器，多图上传，B站视频嵌入
- **信息流**：推荐/关注/收藏流，瀑布流虚拟列表
- **互动**：点赞/收藏/举报

**相关文件**：
- 后端：`netlify/functions/_lib/routes/articles.ts`
- 前端：`app/pages/create.vue`, `app/pages/post/[id].vue`
- 组件：`app/components/PostCard.vue`, `app/components/PostOverlay.vue`

### 3. 评论系统

- **楼中楼**：支持多级回复
- **富文本**：图片上传、@提及、表情
- **AI 回复**：评论区 @fairy 触发 AI 回复

**相关文件**：
- 后端：`netlify/functions/_lib/routes/comments.ts`
- 前端：`app/components/CommentItem.vue`, `app/components/CommentBody.vue`

### 4. 私信系统（敲敲）

- **私聊**：一对一聊天
- **群聊**：多人聊天，成员管理
- **AI 对话**：与 Fairy AI 角色对话
- **消息类型**：文本、图片、B站视频

**相关文件**：
- 后端：`netlify/functions/_lib/routes/dm.ts`
- 前端：`app/components/KnockKnockModal.vue`, `app/components/DmMessageItem.vue`, `app/components/DmComposer.vue`
- Composable：`app/composables/useDmConversations.ts`

### 5. 通知系统

- **通知类型**：点赞、评论、@提及、关注
- **免打扰**：全局免打扰、按类型免打扰
- **存储**：Netlify Blobs，每用户独立前缀

**相关文件**：
- 后端：`netlify/functions/_lib/notify.ts`, `netlify/functions/_lib/routes/notifications.ts`
- 前端：`app/pages/profile/[id].vue`（通知 Tab）

### 6. 用户系统

- **个人主页**：名片、统计、帖子列表
- **等级体系**：发帖/评论/获赞累积经验
- **关注/粉丝**：社交关系

**相关文件**：
- 后端：`netlify/functions/_lib/routes/profiles.ts`, `netlify/functions/_lib/routes/interactions.ts`
- 前端：`app/pages/profile/[id].vue`

### 7. 后台管理

- **用户管理**：搜索/添加/禁用/删除用户
- **内容管理**：帖子/评论/举报管理
- **系统设置**：站点配置、功能开关

**相关文件**：
- 后端：`netlify/functions/_lib/routes/admin.ts`
- 前端：`app/pages/admin/*.vue`
- API：`app/composables/useAdminApi.ts`

## 开发环境

### 环境要求

- Node.js ≥ 20.18
- npm
- Netlify CLI（本地开发需要）

### 本地开发

```bash
# 安装依赖
npm install --legacy-peer-deps

# 启动开发服务器
netlify dev
```

### 构建部署

```bash
# 构建静态站点
npm run generate

# 预览
npx serve .output/public
```
