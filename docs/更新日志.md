### 修复
- **委托总数为负**：`admin/stats` 的 `postCount` 改为直接取信息流长度（发布即入流），不再依赖可能被并发读-改-写漂移的计数器；`bumpStats` 同步改为 etag 条件写（CAS + 重试），防止 userCount 等计数并发丢更新。
- **后台帖子管理缺删除按钮**：草稿/待审/下架状态下，「发布」按钮右侧新增「删除」按钮（彻底删除：草稿删档、已发布标记删除并移出信息流）。
- **清空全部帖子数据**：一次性清除所有帖子、评论、点赞、收藏、已读记录、帖子/评论相关举报、草稿索引与内容统计（版块、用户、上传库保留），统计归零（临时接口，使用后已移除）。
- **后台「最新注册用户」出现两个未知用户**：`admin/stats` 的 `recentUsers` 此前只排除 `by-email` 索引，把 `users/by-uid/*` 索引文档误当用户显示。已修正过滤（同时排除 `by-uid`/`by-github`），并清除一条失效的 uid 索引、补齐管理员缺失的 uid 索引（临时接口，使用后已移除）。
- **米游社登录优雅降级**：`POST /api/auth/mihoyo/qr` 改为返回 `501 + "米游社登录暂未开放"`，替代原先返回空 `qrUrl` 导致的二维码渲染报错。真正的米游社扫码需对接其官方 passport API（含私有请求头，且违反其服务条款），暂不接入。
- **创建草稿/发表评论接口 404**：路由用 `s.length === 3` 匹配 `POST /api/articles` 与 `POST /api/comments`（实际路径为 2 段），导致创建草稿与发表评论永远匹配不到。已改为 `s.length === 2`。
- **Blobs 读取一致性**：`getJson`/`exists` 改用 `consistency: "strong"`，消除发布后列表延迟可见、以及删除帖子短暂回现的问题（此前默认 eventual 一致性 + 索引读-改-写竞态）。
- **feed 索引原子化（CAS）**：`feedAdd/feedRemove/feedUpdate/feedUpsert` 改用「读-改-写 + etag 条件写 + 重试」，消除并发发布/删除/计数时索引丢更新或旧数据回写覆盖删除的问题。

### 新增
- **帖子审核流程**：
  - 站点设置「新帖需审核后发布」现在**真正生效**：开启后 `publishDraft` 把帖子置为 `pending`（进入待审队列，不进信息流、不计发布数），发布接口返回 `{ status: "pending" }`，前端提示"已提交审核"。
  - 后台帖子管理新增**审核操作**：待审帖子可「通过」（→ 已发布，进信息流并计数）或「驳回」（→ 退回草稿）；后台 `updatePost` 状态切换时同步信息流与统计（postCount / articleCount）。

### 新增
- **GitHub OAuth 登录**：
  - 后端 `POST /api/auth/github/callback`（授权码 → access_token → 用户信息 → 建号/登录，Blobs 存储 `users/by-github/<id>` 映射）。
  - 前端登录弹窗新增「使用 GitHub 登录」按钮（跳转 GitHub 授权，`state` 防 CSRF）；`/login` 页处理回调并签发本站 JWT。
  - 环境变量：`NUXT_PUBLIC_GITHUB_CLIENT_ID`、`GITHUB_CLIENT_ID`、`GITHUB_CLIENT_SECRET`、`GITHUB_REDIRECT_URI`。
  - 使用方式：在 GitHub 注册 OAuth App，Authorization callback URL 填 `<站点>/login`。
- **第三方登录按钮改圆形图标**：登录弹窗的米游社 / GitHub 按钮由文字胶囊改为**圆形图标按钮**（48px 圆形、白色底、图标居中，悬停描边高亮），去文字、加 `title`/`aria-label`。
- **UID 自动生成机制**：每个用户分配唯一 8 位数字 UID（`10000000~99999999`）。注册、GitHub 登录、初始管理员建号时自动生成，`users/by-uid/<uid>` 索引保证唯一；旧用户通过 `seedVersion=3` 一次性回填；个人主页 `uid`/`userId` 改为返回数字 UID（此前返回 documentId 字符串）。

## [v0.3.0] - 2026-08-08

### 重构
- **存储全面切换到 Netlify Blobs**：移除 Netlify Database（Postgres）与 `netlify/database/migrations`。
  - 结构化数据（用户/帖子/评论/点赞等）以 JSON 文档存入 `data` store。
  - 图片字节存 `uploads` store（保持 sharp 转 WebP）。
  - 信息流改用 `_indexes/feed.json` 索引文档，一次读取即可排序/过滤/分页。
  - 新增草稿、用户评论、评论查找、上传 documentId、邮箱等索引文档。
- 移除 `@netlify/database` 依赖。

### 说明
- Blobs 无事务：计数采用读-改-写，极端并发下可能出现轻微偏差；`list()` 仅返回 key，需前缀扫描过滤。适用中小数据量。
