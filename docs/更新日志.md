## [v0.3.0] - 2026-08-08

### 重构
- **存储全面切换到 Netlify Blobs**：移除 Netlify Database（Postgres）与 `netlify/database/migrations`。
  - 结构化数据（用户/帖子/评论/点赞等）以 JSON 文档存入 `data` store。
  - 图片字节存 `uploads` store（保持 sharp 转 WebP）。
  - 信息流改用 `_indexes/feed.json` 索引文档，一次读取即可排序/过滤/分页。
  - 新增草稿、用户评论、评论查找、上传 documentId、邮箱等索引文档。
- 移除 `@netlify/database` 依赖。

### 说明
- Blobs 无事务：计数采用读-改-写，极端并发下可能出现轻微偏差；`list()` 仅返回 key，需前缀扫描过滤。适用中小数据量。

## [v0.2.1] - 2026-08-08

### 修复
- **Netlify 部署解析失败**：移除 `netlify.toml` 中无效的 `[[functions."api"]]` 数组语法。JS/TS 函数路由改由源码内 `export const config = { path: "/api/*" }` 声明。

## [v0.2.0] - 2026-08-08

### 新增
- **绳网论坛全栈项目**首期落地（基于 InterKnot-Web 模板 UI）：
  - 前端：Nuxt 4 + Pinia + TanStack Vue Query，复刻《绝区零》绳网界面。
  - 后端：Netlify Functions 单入口 `/api/*`，约 50 个端点（认证 JWT、帖子/草稿/搜索、评论楼中楼、点赞/收藏/关注/拉黑/举报、个人主页、上传、后台管理）。
  - 后台管理端 `/admin`：数据概览、用户、帖子、评论、版块、站点设置；仅管理员可访问（路由守卫 + 布局兜底）。
  - 图片上传：服务端 sharp 自动转 WebP、限尺寸、剥 EXIF，存 Netlify Blobs。
  - 数据库：Netlify Database Postgres 迁移 `0001_init.sql`（12 张表，后续版本已移除）。
  - 文档：`docs/ai设计建议.md` 架构设计。
- 初始化默认版块与管理员账号（`ADMIN_INITIAL_EMAIL` / `ADMIN_INITIAL_PASSWORD`）。
